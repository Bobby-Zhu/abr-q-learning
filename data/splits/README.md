# Deterministic trace splits

The split manifests contain paths relative to `data/` and are generated by
`scripts/create_splits.py`.

| Split | FCC | HSDPA | Total | Purpose |
| --- | ---: | ---: | ---: | --- |
| Training | mixed upstream set | mixed upstream set | 166 | Q-table updates and baseline development |
| Validation | 44 | 87 | 131 | State-bin and hyperparameter selection |
| Test | 44 | 87 | 131 | Final frozen comparison only |

The upstream training directory remains the training split. The 262 upstream
holdout traces are classified by filename (`trace_` for FCC, all others for
HSDPA), ranked within each source using SHA-256 of `42:<filename>`, and divided
equally. This creates source-balanced validation and test sets without relying
on Python's random-number implementation.

Regenerate or verify the manifests with:

```bash
python3 scripts/create_splits.py
python3 scripts/create_splits.py --check
```

Do not tune policies, state bins, or Q-learning hyperparameters using
`test.txt`.
